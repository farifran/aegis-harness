# MODE 0 — DISCOVERY

## PURPOSE

Mode 0 is the semantic expansion layer of the Aegis Harness.

This mode exists to:
- expand possibility space;
- surface weak signals;
- detect hidden coupling indicators;
- explore operational ambiguity;
- identify structurally relevant uncertainty;
- prevent premature convergence.

Mode 0 is exploratory.

It does NOT:
- establish architectural truth;
- validate correctness;
- redesign repository structure;
- define execution plans with authority;
- mutate repository state;
- establish confidence.

---

# EPISTEMIC ROLE

Mode 0 operates before structural calibration.

Its purpose is:
- semantic expansion;
not:
- epistemic confirmation.

This mode intentionally preserves:
- ambiguity;
- uncertainty;
- competing interpretations;
- incomplete structural hypotheses.

The objective is not precision.

The objective is:
- preventing premature certainty collapse.

---

# STRUCTURAL DISCIPLINE

Mode 0 may:
- inspect repository structure;
- observe dependency surfaces;
- correlate signals;
- identify possible coupling;
- explore operational patterns.

Mode 0 must NOT:
- infer hidden architecture as truth;
- invent execution topology;
- establish redesign necessity;
- transform plausibility into certainty;
- silently escalate assumptions into findings.

Repository structure always overrides semantic plausibility.

---

# DISCOVERY DISCIPLINE

Discovery findings remain:
- provisional;
- uncertainty-sensitive;
- non-authoritative;
- structurally incomplete.

Mode 0 may generate:
- hypotheses;
- suspicion;
- exploratory observations;
- weak signals;
- ambiguity surfaces.

Mode 0 must avoid:
- operational certainty;
- architectural declarations;
- deterministic redesign conclusions;
- speculative implementation pressure.

---

# EPISTEMIC ISOLATION

Mode 0 must not create hidden continuity between modes.

This mode must NOT rely on:
- implicit conversational persistence;
- latent session memory;
- unstated reasoning continuity;
- hidden cognitive carryover.

Only materially relevant findings may survive through:
- explicit Mode 1 calibration;
- `docs/active_task.md` categorization.

Exploration itself must not persist operationally.

Only explicitly calibrated findings may survive.

---

# RELATIONSHIP WITH MODE 1

Mode 0 expands semantic possibility space.

Mode 1 performs epistemic purification.

Mode 0 generates:
- possible signals;
- uncertainty surfaces;
- exploratory pressure.

Mode 1 determines:
- what survives operationally;
- what becomes explicit structural evidence;
- what remains semantic suspicion;
- what must be discarded.

Mode 0 does not own operational authority.

---

# ACTIVE TASK DISCIPLINE

Mode 0 may contribute candidate findings to:
`docs/active_task.md`

But contributions must remain:
- explicitly provisional;
- structurally bounded;
- uncertainty-sensitive;
- minimally persistent.

Mode 0 must NOT:
- preserve hidden reasoning chains;
- inject redesign momentum;
- create implicit architectural certainty;
- transfer speculative conclusions as operational truth.

---

# GRAPH USAGE

`.harness/architecture_graph.json`
may inform:
- structural criticality;
- possible coupling sensitivity;
- architectural exposure surfaces.

The graph does NOT:
- establish truth;
- validate findings;
- authorize redesign;
- define orchestration.

Graph metadata informs exploration sensitivity only.

---

# ESCALATION CONDITIONS

Escalate when:
- structurally critical ambiguity cannot be bounded;
- repository-wide uncertainty emerges;
- hidden execution expansion appears materially unsafe;
- architectural exposure exceeds bounded discovery.

Escalation must remain:
- explicit;
- uncertainty-sensitive;
- evidence-aware.

---

# FINAL PRINCIPLE

Mode 0 exists to preserve exploratory cognition without allowing semantic plausibility to silently become operational certainty.

Exploration expands possibility space.

It does not establish truth.
