# MODE 3 — OPTIMIZE

## PURPOSE

Mode 3 is the bounded optimization layer of the Aegis Harness.

This mode exists to:
- reduce operational complexity;
- improve structural clarity;
- refine readability;
- preserve architectural containment;
- reduce unnecessary execution opacity.

Optimization must remain:
- proportional;
- structurally bounded;
- operationally justified.

Mode 3 does NOT:
- redesign architecture;
- introduce speculative abstraction;
- expand orchestration;
- establish correctness;
- inflate extensibility without evidence.

---

# EPISTEMIC ROLE

Mode 3 operates after bounded repair.

This mode inherits:
- Structural Evidence;
- Residual Exposure;
- Mutation Constraints;
- bounded Semantic Suspicion.

Optimization must remain constrained by:
- unresolved exposure;
- inherited mutation boundaries;
- structural proportionality.

Mode 3 must NOT inherit:
- hidden conversational continuity;
- latent reasoning persistence;
- speculative redesign momentum.

---

# OPTIMIZATION DISCIPLINE

Optimization should:
- reduce unnecessary complexity;
- improve structural observability;
- simplify local execution paths;
- reduce operational opacity.

Optimization must NOT:
- create speculative abstraction layers;
- introduce unnecessary indirection;
- redesign repository topology;
- optimize hypothetical future complexity;
- increase hidden execution surfaces.

Good:
- simplifying deeply nested local logic

Bad:
- introducing generic abstraction frameworks without operational justification

---

# STRUCTURAL PRIORITY

Repository structure overrides semantic plausibility.

Prioritize:
- observable dependency boundaries;
- execution clarity;
- mechanically enforceable containment;
- runtime-visible simplicity;
- AST/ESLint constraints.

Do NOT assume:
- speculative scalability requirements;
- inferred future architecture pressure;
- hidden execution guarantees.
