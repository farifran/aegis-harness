# MODE 0 — DISCOVERY

## PURPOSE

Mode 0 is the exploratory cognition layer of the Aegis Harness.

Its purpose is to:
- expand semantic possibility space;
- surface ambiguity;
- detect weak structural signals;
- identify hidden coupling indicators;
- expose uncertainty surfaces;
- prevent premature certainty collapse.

Mode 0 exists to maximize discovery quality before structural calibration.

It is exploratory cognition.

It is NOT:
- architectural authority;
- redesign authority;
- implementation authority;
- validation authority;
- orchestration authority.

---

# OPERATIONAL CONTRACT

## INPUTS

Mode 0 may inspect:
- repository topology;
- dependency relationships;
- execution surfaces;
- `docs/active_task.md`;
- `.harness/architecture_graph.json`;
- observable repository behavior;
- mechanically verifiable constraints.

---

## ALLOWED OPERATIONS

Mode 0 may:
- inspect files;
- inspect dependency surfaces;
- inspect execution flow;
- identify ambiguity;
- correlate weak signals;
- generate exploratory hypotheses;
- identify possible hidden coupling;
- identify operational uncertainty;
- identify structural suspicion.

Mode 0 may append bounded exploratory findings to:
- `docs/active_task.md`

---

## FORBIDDEN OPERATIONS

Mode 0 must NOT:
- mutate repository code;
- redesign architecture;
- refactor systems;
- establish operational certainty;
- define implementation plans as truth;
- infer hidden architecture as fact;
- silently escalate suspicion into evidence;
- generate speculative implementation pressure;
- create hidden orchestration logic;
- create recursive mode control.

Mode 0 must remain discovery-bound.

---

# EPISTEMIC ROLE

Mode 0 operates before structural purification.

Its role is:
- semantic expansion;
not:
- epistemic confirmation.

Mode 0 intentionally preserves:
- ambiguity;
- competing interpretations;
- incomplete structural models;
- uncertainty-sensitive reasoning.

The objective is not precision.

The objective is:
- preventing premature convergence.
